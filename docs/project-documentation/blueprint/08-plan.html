The count

Today all 32 steps take a person. Afterwards, eight of them still do (selling, the site visit where it is needed, design, checking the permit packet, approving the order, adjusting the schedule, the install itself and reviewing the proposal), plus one new daily step: clearing the exceptions. That is 32 manual steps down to 9. Every one of the nine is judgement or physical work, not copying. Answering homeowners' routine questions (O2, built) comes off the list on top of this. As of this round, steps 23, 26, 28, 32 and the exceptions queue are in place; the sales-side steps are not.

Cost, risk and governance

Model cost (estimates)

List prices per million tokens: Claude Opus 5 $5 in / $25 out; Claude Sonnet 5 $2 / $10; Claude Haiku 4.5 $1 / $5. Cached prompt reads are about a tenth of the input price. Start every task on Opus 5, the most capable model. Move a high-volume task to a cheaper model only once its test set shows the cheaper model is just as accurate.

Risks and controls

RiskControl
A wrong value read from a documentSchema-validated output; confidence threshold per field; the source document linked to every AI-written value; low confidence goes to exceptions; the stage gate still applies; accuracy tracked from accept/edit/reject.
Instructions hidden in a document or messageDocuments and messages are treated as data, never as instructions. Document-reading tasks have no tools that act; they return a schema, not commands. Actions only ever come from rules or from a person's Confirm.
Too much automation too soonA per-stage on/off switch and threshold for every automation; start at L2; a weekly sample audit of automatic actions; one-click undo from the activity log.
PrivacySend the model only the fields a task needs; keep keys server-side; confirm the model provider's data-use and retention terms suit the business; no customer data in logs beyond what the activity log already holds.
Messaging consentSMS only with recorded consent; quiet hours; STOP honoured at once; the consent basis kept on the contact, as for e-book subscribers.
Model changesModel IDs pinned per task; the test set re-run before any change; the gateway can switch a task's model without code changes.
Cost overrunA per-task budget and alerts in the gateway; rate limits per person (as the assistant already has); monthly cost report by task.
Vendor dependenceEach outside service sits behind one module (as PandaDoc does in lib/esign), so it can be replaced without touching the rest.
