Glossary

TermMeaning
AdderAn extra line item on a solar job (e.g. main panel upgrade, trenching, roof work).
AHJAuthority having jurisdiction: the city or county that issues the permit and inspects.
Contact stageWhere a person stands in the sale (created → signed / lost). Belongs to the contact.
Deal stageThe opportunity's own stages (New → Contract out → Won / Lost).
Drive UpdatedThe gate closing each stage: the job's shared drive has the stage's documents.
EnergizationThe system switched on and producing; monitoring active.
HDM NTPNotice to proceed from the finance partner before installation.
HOAHomeowners' association approval, where the property has one.
ICAInterconnection agreement with the utility.
kW / kWhSystem size (kilowatts, DC) / energy produced or used (kilowatt-hours).
LifecycleLead, prospect, customer, past customer: derived from the person's projects.
MigrationAn ordered SQL file that changes the database schema.
OffsetThe share of annual usage the system is expected to produce.
PM / OpsProject manager: the role that runs the pipeline.
PPA / leaseThird-party ownership: the homeowner pays for power or rent, not the system.
PTOPermission to operate, granted by the utility after inspection.
Rapid shutdownThe electrical code requirement to de-energize rooftop conductors quickly for firefighter safety.
RLSRow-level security: database rules that decide which rows each user may read or change.
StampsA licensed engineer's approval on the plan set.
The holdThe rule that keeps a signed contact in Contract signed while their project exists.
